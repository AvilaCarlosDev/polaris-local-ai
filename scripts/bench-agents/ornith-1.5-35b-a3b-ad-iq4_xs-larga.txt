```python
import re

_SEMVER_RE = re.compile(
    r"^(?P<major>0|[1-9]\d*)\.(?P<minor>0|[1-9]\d*)\.(?P<patch>0|[1-9]\d*)"
    r"(?:-(?P<prerelease>[\dA-Za-z-]+(?:\.[\dA-Za-z-]+)*))?"
    r"(?:\+(?P<build>[\dA-Za-z-]+(?:\.[\dA-Za-z-]+)*))?$"
)


def parse_semver(s: str) -> tuple[int, int, int]:
    m = _SEMVER_RE.match(s)
    if not m:
        raise ValueError(f"Invalid semantic version: {s!r}")
    return int(m["major"]), int(m["minor"]), int(m["patch"])
```

La regex valida el formato semver 2.0.0 completo (pre-release y build opcionales) y solo extrae los tres números. Uso `0|[1-9]\d*` en cada componente para rechazar ceros a la izquierda como `01.2.3`.
